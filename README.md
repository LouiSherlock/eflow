# 阅流

本地离线的电子书阅读器，基于 Tauri 2 + React 19，可运行在桌面与 Android。

## 产品说明

阅流是一款只读本地文件的阅读工具。导入的书籍与封面保存在本机浏览器数据库，书架、收藏和阅读进度记录在本地，不需要账号，也不会上传任何内容。

- **格式**：支持 EPUB、MOBI、AZW3 和纯文本 TXT；加密或受 DRM 保护的文件无法打开，PDF 等格式暂不支持。
- **书架**：封面网格、搜索、收藏，自动记住最近在读的一本，可一键继续阅读。
- **阅读**：翻页、目录跳转、点击屏幕边缘翻页，桌面端支持方向键翻页。
- **排版**：可调整字号、行距、段距与两端对齐，支持浅色 / 深色主题，电子书会在下一次翻页时应用新设置。
- **进度**：按百分比和阅读位置保存，翻页后自动记录；换设备或清除应用数据后不会同步。

## 开发

```bash
pnpm tauri dev          # 桌面
pnpm tauri android dev  # Android（模拟器/真机）
```

端口 1420 被占或进程残留时，手动结束占用该端口的进程（项目没有清理脚本）。

## 清除缓存

在项目的 src-tauri 目录执行：

`cargo clean`

## 构建时候可能出现的问题

### 内存引用冲突

降低同时构建线程

```bash
$env:CARGO_BUILD_JOBS=1
pnpm tauri build
```


也可以在项目的 .cargo/config.toml 中永久设置：

```toml
[build]
jobs = 2
```


### 批量生成图标

```bash
pnpm tauri icon ./public/logo.png
```
